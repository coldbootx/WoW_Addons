NetInfo is a lightweight, professional looking performance overlay for the classic version of World of Warcraft.
It displays real time statistics that are useful for both casual players and raiders who want to keep an eye on FPS, latency, bandwidth, and addon memory consumption without leaving the game.

The addon follows the UI guidelines for Blizzard’s default interface, uses colour‑coded values for quick visual scanning, and can be dragged anywhere on the screen.
