NetInfo Classic Era WoW Addon
Version: 1.2
Author: William Butler

Features:
- Displays FPS, Home/World Latency
- Lists each Addon's memory usage and total memory in MB
- Latency over 25ms shown in red
- Tooltip with Shift + Click instructions
- Resizable frame with bottom-right corner grabber
- Slash commands: /netinfo help, /netinfo version, /netinfo show, /netinfo hide
- Supports multiple languages via external locale files
- Frame auto-shows on login

Instructions:
- Shift + Left Click: Move the frame
- Shift + Right Click: Show/Hide the frame
- Drag the bottom-right corner to resize
- scrollable addon list: the UI now includes a scroll frame so long addon lists won’t overflow the window.
- mouse wheel scrolling support for easier navigation.
- Hover over the frame for instructions

Localization:
