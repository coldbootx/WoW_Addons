NetInfo Addon (Classic Only)

Version: 1.3
Description:

NetInfo is a lightweight World of Warcraft addon designed for Classic WoW that provides real-time network and performance information. It features a clean, customizable interface with a blue-themed border, right-aligned alternating row striping, and an easy-to-move, resizable frame.
Features

    Performance Monitoring: Displays current FPS, home latency, and world latency.
    Add-On Memory Usage: Shows memory usage for all loaded addons, with a total.
    Customizable Frame: Move and resize the main display window.
    Color-coded Data: Network stats are color-coded for quick assessment.
    Alternating Row Striping: Improves readability with striped rows.
    Localization Support: Supports multiple languages (enUS, deDE, frFR, esES, esMX, ruRU, koKR, zhCN, zhTW).
    Slash Commands: Easy command line control (/netinfo, /netinfo help, /netinfo show, /netinfo hide, /netinfo version).
    Auto-Show on Login: Automatically displays the frame when you log in.

Usage:

    To toggle the display, use /netinfo.
    Drag the frame's bottom-right corner to resize.
    Hold Shift + Left click on the frame to move it.
    Hold Shift + Right click to hide/show the frame.
