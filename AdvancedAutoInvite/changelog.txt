Advanced Auto Invite - Changelog
=============================================

Version 1.5 (Current)
=====================
• Added: GUI configuration panel with scrollable interface
• Added: Status display showing group info and permissions
• Added: Feedback system with color-coded messages
• Added: Action buttons (Clear Cache, Test Permissions)
• Improved: Connected realm handling
• Improved: Name comparison for better group detection
• Improved: EditBox handling in Classic Era
• Fixed: Whisper message saving issues
• Fixed: Permission checks for Classic Era
• Fixed: Spam protection with full names
• Changed: Default spam cooldown to 10 seconds
